# Favorite GIFs Manager

A user plugin for Equicord to manage your favorite GIFs. 

Discord's native GIF favorite system is pretty annoying to deal with if you have a lot of them. This plugin adds a dedicated UI to view, bulk-delete, backup, and restore your GIFs.

## Features
- export/import backups as JSON
- manage/bulk un-favorite your gifs easily.
